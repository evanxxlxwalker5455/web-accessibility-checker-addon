## About the Addon

Accessibility Checker Addon brings HTML accessibility review into the browser workflow. It helps expose common concerns while a page is being examined, allowing developers and reviewers to investigate issues alongside the content instead of postponing the review until later.

The 2026 release remains lightweight and browser-based, making it suitable for checking several pages in succession. Developers, content authors, and reviewers can use it to inspect web content and discover accessibility issues earlier during development, editing, or testing.
